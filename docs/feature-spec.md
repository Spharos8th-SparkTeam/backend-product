# backend-product 기능명세서 (상품 서비스)

| No. | 역할 | 화면구분 | 기능 이름 | 요구사항 설명 | 비고 | 개발 구분 |
|---|---|---|---|---|---|---|
| 1 | 구매자/판매자 | 메인페이지 | 추천 상품 | - 신상품, 인기상품(인기순은 찜 수로 조회하고 찜 수가 같은 경우 조회수로 순위를 나눔) 조회<br>- 각각 25개 조회 (5x5) 및 더보기 버튼(더보기 버튼을 누르면 판매 상품 목록 조회로 이동되고, 자동으로 필터링 됨) | | 중 |
| 2 | 구매자/판매자 | 메인페이지 | 상품 카드 | - 상품 썸네일 이미지, 상품명, 가격, 판매 상태 | | 상 |
| | 구매자/판매자 | 프로필 페이지 | 프로필 조회 | - 닉네임, 프로필사진, 평균별점, 후기 수, 거래 수<br>- 액션탭(판매 중인 상품, 판매 완료 상품, 리뷰)<br>- 판매 중인 상품 무한 스크롤로 구현<br>- 리뷰 10개씩 무한 스크롤로 구현 | | 상 |
| 5 | 구매자/판매자 | 판매 등록 | 사진/동영상 가져오기 | - 사진첩에서 가져오기만 가능 (사진촬영 불가능)<br>- 사진 및 동영상은 최대 10개 첨부 가능<br>- 가장 첫번째로 업로드된 이미지가 대표 이미지가 됨.<br>- 사진은 최소 1개 이상 첨부<br>사진 형식 : png, jpg, jpeg<br>동영상 형식 : mp4, mov<br>- 사용자가 상품 등록을 완료한 이후 미디어 정보가 데이터베이스에 저장됨 | | 상 |
| 6 | 구매자/판매자 | 판매 등록 | 상품 정보 등록 | - 사진이나 동영상(url)<br>- 대표 이미지 변경 시 원하는 이미지를 가장 앞으로 드래그하면 그 이미지가 대표 이미지가 됨<br>- 상품명 : 공란 불가<br>- 카테고리<br>1차 필터링 : 물품 종류(피규어/프라모델, TCG, 레고, 아트토이, 인형, 스퀴시/피젯토이)<br>2차 필터링 : 국가(일본, 중국, 대만, 미국, 덴마크, 체코, 독일)<br>- 상품설명 (최소 10자 이상 입력. 제목 공란 불가)<br>- 버튼(추천 가격 보기)<br>- 가격 (0달러 ~ 100만 달러사이의 숫자만 입력 가능)<br>- 판매 상태 : 판매중/예약중/판매완료 구분, 기본값은 판매중<br>- 상품 등록 완료 후 상품 목록 조회 페이지로 이동 | 회원만 접근 가능 | 상 |
| | 구매자/판매자 | 판매 등록 | 업로드 사진 감지 후 시세 조회 | - 판매자가 추천 가격 보기 버튼을 누르면 대표 이미지가 S3에 임시 저장됨.<br>- 가장 첫번째로 업로드된 이미지가 대표 이미지이고, 대표이미지를 삭제하면 다음 순서의 이미지가 대표 이미지가 됨.<br>- 동영상은 분석 대상 아님<br>- 대표이미지를 AI로 어떤 상품인지 감지하고 키워드를 결과로 생성<br>- 비슷한 | | 상 |
| | 구매자/판매자 | 판매 상품 관리 | 판매 상품 목록 조회 | - 상품 썸네일 이미지, 상품명, 가격, 판매 상태<br>- 25개(5x5) 조회 및 페이지네이션<br>- 필터링(판매 상태 : 전체, 판매중, 예약중, 판매완료) | 회원만 접근 가능 | 상 |
| | 구매자/판매자 | 판매 상품 상세 조회 | 판매 물품 조회 | - 상품 사진목록, 상품명, 상품 가격(달러만 취급), 상세 설명, 조회수, 찜 수<br>- 판매자 정보(닉네임, 별점, 후기 개수, 거래 횟수)<br>- 버튼(채팅, 찜, 구매하기, 신고) | | 상 |
| 11 | 구매자/판매자 | 판매 상품 관리 | 판매 상품 수정 | - 사진이나 동영상(url)<br>- 대표 이미지 변경 시 원하는 이미지를 가장 앞으로 드래그하면 그 이미지가 대표 이미지가 됨<br>- 상품명 : 공란 불가<br>- 카테고리<br>1차 필터링 : 물품 종류(피규어/프라모델, TCG, 레고, 아트토이, 인형, 스퀴시/피젯토이)<br>2차 필터링 : 국가(일본, 중국, 대만, 미국, 덴마크, 체코, 독일)<br>- 상품설명 (최소 10자 이상 입력. 제목 공란 불가)<br>- 버튼(추천 가격 보기)<br>- 가격 (0달러 ~ 100만 달러사이의 숫자만 입력 가능)<br>- 판매 상태 : 판매중, 예약중, 판매완료<br>(판매 완료 상태에서는 판매 상태를 제외한 다른 요소들은 수정 불가능하다)<br>- 완료 시 판매 상품 상세 보기로 이동 | 해당 상품의 판매자만 접근 가능 | 상 |
| 12 | 구매자/판매자 | 판매 상품 관리 | 판매 상품 삭제 | - 삭제 시 최종 삭제 여부를 모달로 알림<br>- 삭제 후에 상품 데이터는 데이터베이스에 유지<br>- 삭제 후에 사진 및 동영상은 3개월 후 데이터베이스에서 삭제<br>- 완료 시 상품 목록 조회로 이동 | | 상 |
| | 구매자/판매자 | 검색한 상품 목록 조회 | 검색한 상품 리스트 | - 검색 키워드, 검색 결과, 결과 개수<br>- 상품 명으로만 검색<br>- 검색 후 -> 카테고리를 1차, 2차를 선택할 수 있게 두기<br>- 판매 상품 목록(썸네일 사진, 상품제목, 가격, 판매 상태, 찜 수)<br>- 버튼(찜 버튼 : 상품 썸네일에서 찜 가능)<br>- 한 페이지에 5x5, 페이지네이션 | 상품명과 카테고리로 검색 가능 | 상 |
| 18 | 구매자/판매자 | 상품 목록 조회 | 헤더 | 카테고리, 상품 검색 | | 상 |
